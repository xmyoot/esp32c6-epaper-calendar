# Tool and reference provenance

- kicad-happy, https://github.com/aklofas/kicad-happy, local commit `6a91aaaea124152b2923326c1cf77278e0999cd4`. Schematic, PCB, cross-domain, EMC, thermal, lifecycle and Gerber analyzers were used. The tool is not vendored; its license is available in its upstream repository.
- KiCadRoutingTools, https://github.com/drandyhaas/KiCadRoutingTools, local commit `fd59a050e258581d5938c4d9456bbfeb13240e67`. Native router binary v0.23.1, SHA256 `5f36bd314cfe54c450941d0a3c2a270badca239c5054fe00e627550b42bf0a68`. The tool is not vendored; retain its upstream MIT license when installing. Accepted routing used explicit net lists, locked critical copper, no pre-existing rip-up, 0.20mm clearance, 0.60/0.30mm vias, `--escalation off`, `--fab-tier standard`, and `--same-net-pad-clearance 0.25`. Rejected exploratory outputs are retained under `analysis/routing`, not fabrication sources.
- KiCad 10.0.7 CLI and bundled pcbnew generated native project exports and authoritative ERC/DRC. Vendored standard symbols/footprints in `hardware/` originate from the installed KiCad libraries; retain their upstream CC-BY-SA 4.0 licensing and KiCad libraries exception when redistributing. Project-specific connector symbols are original design work. Standard 3D model references still use KiCad's installed model directory; no XIAO module model is included in the board render.
- Seeed Studio official native XIAO ESP32C6 project, downloaded from its wiki hardware-resources link, supplies module pin order, 15.24mm drilled-header row spacing and regulator identity. Preserve upstream design notices in the archive under `references/`.
- Good Display GDEY075T7 specification rev1.0, 2021-03-10, mirrored by LaskaKit; original manufacturer-authored document cached in `references/`. Component manufacturer PDFs are cached under `datasheets/`. Reference documents remain their authors' property.
- Arduino-ESP32 3.3.12, GxEPD2 1.6.9, Adafruit GFX 1.12.6 and BusIO 1.17.4 were used to compile the firmware. They retain their respective upstream licenses. See `firmware/versions.txt`.
- Local Arduino CLI 1.5.2-rc.1 downloaded from Arduino. Its packaged ctags host executable was incompatible with this Apple Silicon host. `arduino/ctags` commit `abc8fca7499f44c725122881cd380a88c37abe0e` was compiled locally, with its internal `__unused__` macro renamed `CTAGS_UNUSED_` to avoid current macOS SDK macro collisions. Only the project-local tool copy was replaced; no operating-system component or global Arduino installation was modified. Upstream GPL notices remain in `tools/ctags-source`.

This project is an independent portfolio implementation of a supplied brief. There is no claim of sponsorship, product certification, tested hardware, or client endorsement.

Architecture, implementation, firmware and reviews were developed with AI assistance through Codex. KiCadRoutingTools routed the noncritical connections after the switching/current-sense copper was explicitly placed and locked. This is a design study with digital verification, not a record of fabricated hardware or measured performance.
